## Implementation Steps

### Step 1: Create Setup SQL Scripts (infrastructure files)

Create the following SQL scripts in `/Users/mike.dampier/Development/Provider360/infrastructure/`:

**1a. `01_databases.sql`** — Create 5 databases with schemas:

| Database | Schemas |
|---|---|
| `HOSPITAL360_RAW` | `EPIC`, `ERP`, `HR`, `CLAIMS`, `SUPPLY_CHAIN`, `AD_LOGS`, `IOT`, `MARKETPLACE` |
| `HOSPITAL360_INT` | `CLINICAL`, `FINANCIAL`, `OPERATIONS`, `WORKFORCE`, `SUPPLY_CHAIN` |
| `HOSPITAL360_CUR` | `CLINICAL`, `FINANCIAL`, `OPERATIONS`, `WORKFORCE`, `SUPPLY_CHAIN`, `POPULATION_HEALTH`, `GOVERNANCE` |
| `HOSPITAL360_ML` | `FEATURES`, `MODELS`, `PREDICTIONS`, `MONITORING` |
| `HOSPITAL360_APP` | `STREAMLIT`, `SEMANTIC_VIEWS`, `CORTEX_ANALYST` |

**1b. `02_warehouses.sql`** — Create 4 warehouses:

| Warehouse | Size | Config |
|---|---|---|
| `H360_LOAD_WH` | MEDIUM | Auto-suspend 60s, auto-resume |
| `H360_XFM_WH` | LARGE | Auto-suspend 120s, auto-resume |
| `H360_BI_WH` | MEDIUM | Multi-cluster (1-3), auto-suspend 300s |
| `H360_ML_WH` | LARGE | Auto-suspend 120s, auto-resume |

**1c. `03_roles.sql`** — Create role hierarchy:

```
SYSADMIN
  └── H360_ADMIN
        ├── H360_ENGINEER   (RAW rw, INT rw, CUR rw, ML rw)
        ├── H360_ANALYST    (CUR ro, APP ro)
        ├── H360_CLINICIAN  (CUR ro + unmasked PHI, APP ro)
        ├── H360_FINANCE    (CUR.FINANCIAL ro, CUR.OPERATIONS ro)
        └── H360_EXEC       (CUR ro, masked PHI, APP ro)
```

Each role gets USAGE on appropriate warehouses and databases with schema-level grants.

**1d. `04_governance.sql`** — Tags, masking policies, row-access policies:

- **Tags** in `HOSPITAL360_CUR.GOVERNANCE`:
  - `DATA_CLASSIFICATION` (values: `PHI`, `PII`, `FINANCIAL`, `RESTRICTED`, `INTERNAL`, `PUBLIC`)
  - `PII_TYPE` (values: `SSN`, `NAME`, `DOB`, `ADDRESS`, `PHONE`, `EMAIL`, `MRN`)
  - `DATA_DOMAIN` (values: `CLINICAL`, `CLAIMS`, `FINANCIAL`, `DEMOGRAPHIC`, `OPERATIONS`, `WORKFORCE`, `REFERENCE`)

- **Masking policies**:
  - `MASK_SSN` — shows last 4 for non-clinical, full for `H360_CLINICIAN`
  - `MASK_DOB` — shows year-only for `H360_EXEC`, full for clinical
  - `MASK_NAME` — shows role+ID hash for `H360_EXEC`, full for clinical
  - `MASK_MRN` — shows `***` for non-clinical roles

- **Row-access policies**:
  - `RAP_DEPARTMENT` — filters on `DEPT_ID` using a mapping table `HOSPITAL360_CUR.GOVERNANCE.ROLE_DEPT_ACCESS`
  - `RAP_FACILITY` — filters on `FACILITY_ID` for ops roles

**1e. `05_stages_and_file_formats.sql`** — External stages and file formats for RAW layer:

- File formats: `FF_PARQUET`, `FF_CSV`, `FF_JSON`
- Internal stages per source schema (for demo data loading)
