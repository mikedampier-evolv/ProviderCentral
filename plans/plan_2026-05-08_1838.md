## Context

The existing Streamlit app has 10 pages querying `HOSPITAL360_CUR` and `HOSPITAL360_ML` via direct Snowflake sessions. Charts use Plotly with a custom dark theme (`chart_theme.py`). The Provider Chat page calls the Cortex Agent REST API with SSE streaming. 

For React: Since browsers can't safely hold Snowflake credentials client-side, we'll use a lightweight Express proxy that holds credentials from `.env` and forwards SQL requests to Snowflake's SQL REST API. The React frontend calls this local proxy.

### 2. Express proxy server (`server/proxy.ts`)

- Reads `.env` for `SNOWFLAKE_ACCOUNT`, `SNOWFLAKE_USER`, `SNOWFLAKE_PASSWORD`, `SNOWFLAKE_WAREHOUSE`, `SNOWFLAKE_ROLE`
- Exposes `POST /api/sql` — accepts `{ sql: string }`, calls Snowflake SQL REST API, returns rows as JSON
- Exposes `POST /api/agent` — proxies SSE stream to the Cortex Agent API endpoint
- Runs on port 3001; Vite dev server proxies `/api` to it

### 3. Chart theme (`src/lib/chartTheme.ts`)

Port the Python `chart_theme.py` — same COLORS, COLOR_SEQ, dark background layout defaults as a Plotly layout template object.

### 4. Shared components

- **TopNav**: Horizontal nav using shadcn/ui `NavigationMenu`. Pages listed left-to-right matching the Streamlit sidebar order (minus Provider Chat which becomes the floating widget).
- **ChatWidget**: Fixed-position bottom-right. Collapsed = circular button with chat icon. Expanded = 400px-wide panel with message history, input, SSE streaming display. Uses `useChatAgent` hook.
- **KPICard, ChartCard, FilterBar, DataTable**: Reusable building blocks matching the Streamlit page patterns.

### 5. Pages (port 1:1 from Streamlit)

Each page:
- Uses `useSnowflakeQuery(sql)` to fetch data (same SQL queries from the .py files)
- Renders KPIs in a grid row
- Renders charts with `react-plotly.js` using the ported theme
- Includes expandable detail table at bottom

### 6. Provider Chat as floating widget

- Always visible (bottom-right corner) regardless of which page the user is on
- Minimized state: small button with chat icon + "Ask anything" tooltip
- Expanded state: chat panel with message history, streaming responses, suggested questions
- Calls `POST /api/agent` which proxies to Snowflake's Cortex Agent SSE endpoint

### 7. Routing

React Router with pages:
- `/` — Home (demo overview)
- `/dashboard` — Provider 360
- `/readmission` — Readmission & LOS
- `/leakage` — Patient Leakage
- `/or-capacity` — OR Capacity
- `/staffing` — Staffing & Quality
- `/financial` — Financial Performance
- `/denials` — Denials & RevCycle

### 8. Run scripts

- `npm run dev` — starts Vite dev server (port 5173) + Express proxy (port 3001) concurrently
- Vite config proxies `/api` → `http://localhost:3001`
