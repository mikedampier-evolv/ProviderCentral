# Week 5 Plan: Streamlit-in-Snowflake Application

## Context

**What I explored:**
- HOSPITAL360_APP database has 3 empty schemas: `STREAMLIT`, `SEMANTIC_VIEWS`, `CORTEX_ANALYST`
- Schema grants already in place: H360_ANALYST, H360_CLINICIAN, H360_EXEC, H360_FINANCE all have USAGE on STREAMLIT schema
- Account has 135 existing Streamlit apps and multiple compute pools available (AGENTOPS, SYSTEM_COMPUTE_POOL_CPU)
- Warehouse-runtime Streamlit is the simplest deployment: `CREATE STREAMLIT ... QUERY_WAREHOUSE = H360_BI_WH`
- 4 use-case marts (48K-115K rows each), 4 ML prediction tables (92-736 rows), ready for visualization
- Key KPIs available: 200K encounters, 12% readmission rate, 15.2% leakage rate, 84.3% OR utilization, 115K denied claims, 4 ML models with 1,286 prediction rows

**Key design decisions:**
- **Warehouse-runtime** (not container-runtime) — simpler, no compute pool management, sufficient for this dashboard demo
- **Multi-page Streamlit app** — one main file + page files under `pages/` directory
- **Snowpark Python connector** (`snowflake.snowpark`) for data access — native to SiS environment
- **Local development files** in `streamlit/` directory, then staged to Snowflake for deployment
- **6 pages**: Executive Summary (home), 4 use-case pages (one per mart/ML model), ML Insights page

## Implementation Steps

### Step 1: Create `streamlit/environment.yml` — Dependencies

```yaml
name: sf_env
channels:
- snowflake
dependencies:
- plotly=5.18.0
- pandas
```

Plotly provides the interactive charts (time series, bar charts, heatmaps, treemaps). Pandas is pre-installed but listed explicitly. Streamlit and snowflake-snowpark-python are included automatically.

### Step 2: Create `streamlit/streamlit_app.py` — Main entry point + Executive Summary

**Executive Summary page** (the home/landing page):
- **KPI header row**: 6 metric cards using `st.metric()` — Total Encounters, Readmission Rate, Leakage Rate, OR Utilization, Denied Charges, ML Models Active
- **Trend sparklines**: Monthly encounter volume, monthly denial rate, monthly leakage rate (small Plotly line charts)
- **Sidebar**: Global filters for Facility and Date Range (these carry across pages via `st.session_state`)
- **Navigation**: Streamlit native `st.navigation()` for multi-page app

Data source: Aggregate queries against FCT_ENCOUNTER, all 4 marts, ML predictions

### Step 3: Create `streamlit/pages/1_readmission_los.py` — UC2: Readmission & LOS

**Readmission & LOS Dashboard**:
- **Filters**: Facility, Encounter Type, Payer, DRG, Date Range
- **KPIs**: Readmission Rate, Avg LOS Index, Long-Stay %, Avg Cost/Day
- **Charts**:
  - Monthly readmission rate trend line (from MART_READMISSION_LOS)
  - LOS Index distribution histogram by DRG
  - Top 10 DRGs by readmission rate (horizontal bar)
  - Readmission rate by payer type (bar chart)
- **ML Section**: Top Insights drivers table from PRED_READMISSION_DRIVERS — shows which segments are driving readmission rate changes (parsed CONTRIBUTOR column as readable labels, with GROWTH_RATE and RELATIVE_CONTRIBUTION)
- **Detail Table**: Expandable drilldown with patient-level encounter data

### Step 4: Create `streamlit/pages/2_patient_leakage.py` — UC1: Patient Leakage

**Patient Leakage Dashboard**:
- **Filters**: Facility, Referring Specialty, Referred-To Specialty, Payer Type, Date Range
- **KPIs**: Leakage Rate, Lost Revenue, High-Value Referrals Leaked, Top Leaked Specialty
- **Charts**:
  - Monthly leakage rate trend line
  - Leakage by referred-to specialty (horizontal bar)
  - Lost revenue by referring specialty (treemap or stacked bar)
  - Leakage by payer type (pie/donut chart)
- **ML Section**: Top Insights drivers from PRED_LEAKAGE_DRIVERS
- **Detail Table**: Referral-level detail with search/filter

### Step 5: Create `streamlit/pages/3_or_capacity.py` — UC3: OR Capacity

**OR Capacity Dashboard**:

- **Charts**:
  - Block utilization heatmap (blocks × day of week)
  - Monthly utilization trend by block (line chart)
  - Delay distribution (histogram)

### Step 6: Create `streamlit/pages/4_denials_revcycle.py` — UC4: Denials & Revenue Cycle

**Denials & RevCycle Dashboard**:
- **Filters**: Facility (via provider), Payer, Denial Category, Date Range
- **KPIs**: Total Denied Charges, Appeal Rate, Recovery Rate, Avg Days to File
- **Charts**:
  - Monthly denial trend by category (stacked area)
  - Denial category breakdown (donut chart)
  - Top 10 CPT codes by denied charges (horizontal bar)

  - Appeal outcome rates (grouped bar)
- **ML Section**: Anomaly detection — show daily denial counts with expected range band + anomaly flags from PRED_DENIAL_ANOMALIES (Plotly scatter with fill between upper/lower bounds)

### Step 7: Create `streamlit/pages/5_ml_insights.py` — ML Model Overview

**ML Insights Dashboard** (consolidated ML view):
- **Encounter Forecast**: 90-day forecast chart (actual historical + predicted with confidence interval), from PRED_ENCOUNTER_VOLUME joined with VW_DAILY_ENCOUNTER_VOLUME for historical context
- **Denial Anomalies**: Time series with anomaly flags highlighted (red dots on expected-range band chart)
- **Readmission Drivers**: Bar chart of top 10 contributors by relative contribution
- **Leakage Drivers**: Bar chart of top 10 contributors by relative contribution
- **Model metadata**: Model names, training dates (MODEL_RUN_TS), row counts

### Step 8: Create `infrastructure/16_deploy_streamlit.sql` — Deployment SQL

```sql
USE ROLE SYSADMIN;

-- Create internal stage for Streamlit files
CREATE STAGE IF NOT EXISTS HOSPITAL360_APP.STREAMLIT.STG_STREAMLIT_FILES
    ENCRYPTION = (TYPE = 'SNOWFLAKE_SSE');

-- Upload files (via PUT from SnowSQL/CLI, or via Snowsight)
-- PUT file://streamlit/streamlit_app.py @HOSPITAL360_APP.STREAMLIT.STG_STREAMLIT_FILES/
--     AUTO_COMPRESS = FALSE OVERWRITE = TRUE;
-- PUT file://streamlit/environment.yml @...
-- PUT file://streamlit/pages/*.py @.../pages/

-- Create the Streamlit app
CREATE OR REPLACE STREAMLIT HOSPITAL360_APP.STREAMLIT.HOSPITAL360_DASHBOARD
    FROM '@HOSPITAL360_APP.STREAMLIT.STG_STREAMLIT_FILES'
    MAIN_FILE = 'streamlit_app.py'
    QUERY_WAREHOUSE = H360_BI_WH
    TITLE = 'Hospital 360 Dashboard';

-- Grant usage to all H360 roles
GRANT USAGE ON STREAMLIT HOSPITAL360_APP.STREAMLIT.HOSPITAL360_DASHBOARD
    TO ROLE H360_ANALYST;
GRANT USAGE ON STREAMLIT HOSPITAL360_APP.STREAMLIT.HOSPITAL360_DASHBOARD
    TO ROLE H360_CLINICIAN;
GRANT USAGE ON STREAMLIT HOSPITAL360_APP.STREAMLIT.HOSPITAL360_DASHBOARD
    TO ROLE H360_EXEC;
GRANT USAGE ON STREAMLIT HOSPITAL360_APP.STREAMLIT.HOSPITAL360_DASHBOARD
    TO ROLE H360_FINANCE;
```

### Step 9: Execute deployment
1. Create the stage
2. PUT all files to the stage (environment.yml, streamlit_app.py, pages/*.py)
3. CREATE STREAMLIT
4. GRANT USAGE
5. Open in Snowsight to verify

### Step 10: Validate
- App loads without errors in Snowsight
- All 6 pages render with data
- Filters work correctly (changing facility/date range updates charts)
- ML sections display prediction data
- KPI numbers match spot-check SQL queries
