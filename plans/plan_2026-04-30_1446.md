# Week 4 Plan: Cortex ML Models

## Context

**Current state:** 28 tables in HOSPITAL360_CUR — 10 dims, 12 facts, 4 use-case marts (~5.8M total rows). HOSPITAL360_ML database has 4 empty schemas: FEATURES, MODELS, PREDICTIONS, MONITORING. H360_ML_WH (Large) designated for ML workloads.

**Cortex ML functions available:**
- **SNOWFLAKE.ML.FORECAST** — Time-series forecasting (train model → call FORECAST method)
- **SNOWFLAKE.ML.ANOMALY_DETECTION** — Anomaly detection on time series (train with optional labels → call DETECT_ANOMALIES)
- **SNOWFLAKE.ML.TOP_INSIGHTS** — Key driver / contribution analysis (stateless object → call GET_DRIVERS)

**Data shapes verified:**
- 548 days of history (Jul 2023 – Dec 2024), daily granularity
- Monthly encounter volumes: ~5K-6K IP+OBS per month, ~3.8K ED per month
- Daily denial counts: ~200-260 per day across 4 categories
- Daily OR cases: ~55 per day across 6 blocks
- Leakage rate: ~15% monthly, 8 specialties
- Readmission rate: ~12% monthly

**Key design decisions:**
- Feature views in `HOSPITAL360_ML.FEATURES` — provide clean inputs to ML models
- Model objects created in `HOSPITAL360_ML.MODELS` — Cortex ML objects are schema-level
- Prediction outputs materialized into `HOSPITAL360_ML.PREDICTIONS` — for consumption by downstream marts/Streamlit
- All models trained using `H360_ML_WH`

## Implementation Steps

### File 1: `infrastructure/13_ml_feature_views.sql` — Feature engineering views

Create 4 views in `HOSPITAL360_ML.FEATURES` that shape data for ML model inputs:

**1. VW_DAILY_ENCOUNTER_VOLUME** — Daily encounter counts by type for Forecast
- Columns: DATE (TIMESTAMP_NTZ), ENCOUNTER_TYPE (series), ENCOUNTER_COUNT, TOTAL_CHARGES
- Source: FCT_ENCOUNTER grouped by ADMIT_DATE + ENCOUNTER_TYPE
- ~2,200 rows (548 days × 4 types)

**2. VW_DAILY_DENIAL_VOLUME** — Daily denial counts/amounts for Anomaly Detection
- Columns: DATE (TIMESTAMP_NTZ), DENIAL_CATEGORY (series), DENIAL_COUNT, DENIED_CHARGES
- Source: MART_DENIALS_REVCYCLE grouped by SERVICE_DATE + DENIAL_CATEGORY
- ~2,200 rows (548 days × 4 categories)

**3. VW_READMISSION_DRIVERS** — Encounter-level features for Top Insights on readmission
- Columns: READMIT_30_FLAG (label), DRG_CODE, PAYER_TYPE, PATIENT_GENDER, AGE_BUCKET, HCC_BUCKET, DEPT_NAME, ENCOUNTER_TYPE, IS_LONG_STAY, ADMIT_MONTH_LABEL (test=last 3 months)
- Source: MART_READMISSION_LOS
- ~106K rows

**4. VW_LEAKAGE_DRIVERS** — Referral-level features for Top Insights on leakage
- Columns: LEAKAGE_FLAG (label), REFERRED_TO_SPECIALTY, REFERRING_SPECIALTY, PATIENT_PAYER_TYPE, PATIENT_ZIP, IS_HIGH_VALUE, REFERRAL_QUARTER_LABEL (test=last quarter)
- Source: MART_PATIENT_LEAKAGE
- ~48K rows

### File 2: `infrastructure/14_ml_models.sql` — Create and train Cortex ML models

**Model 1: FORECAST_ENCOUNTER_VOLUME** — Multi-series daily encounter forecast
```
CREATE SNOWFLAKE.ML.FORECAST HOSPITAL360_ML.MODELS.FORECAST_ENCOUNTER_VOLUME(
    INPUT_DATA => TABLE(HOSPITAL360_ML.FEATURES.VW_DAILY_ENCOUNTER_VOLUME),
    SERIES_COLNAME => 'ENCOUNTER_TYPE',
    TIMESTAMP_COLNAME => 'DATE',
    TARGET_COLNAME => 'ENCOUNTER_COUNT'
)
```
Then: Forecast 90 days (Jan-Mar 2025) → save to `HOSPITAL360_ML.PREDICTIONS.PRED_ENCOUNTER_VOLUME`

**Model 2: ANOMALY_DENIAL_VOLUME** — Multi-series daily denial anomaly detection
```
CREATE SNOWFLAKE.ML.ANOMALY_DETECTION HOSPITAL360_ML.MODELS.ANOMALY_DENIAL_VOLUME(
    INPUT_DATA => TABLE(HOSPITAL360_ML.FEATURES.VW_DAILY_DENIAL_VOLUME),
    SERIES_COLNAME => 'DENIAL_CATEGORY',
    TIMESTAMP_COLNAME => 'DATE',
    TARGET_COLNAME => 'DENIAL_COUNT',
    LABEL_COLNAME => ''
)
```
Then: Run DETECT_ANOMALIES on recent 6 months → save to `HOSPITAL360_ML.PREDICTIONS.PRED_DENIAL_ANOMALIES`

**Model 3: INSIGHTS_READMISSION** — Top Insights for readmission drivers
```
CREATE SNOWFLAKE.ML.TOP_INSIGHTS HOSPITAL360_ML.MODELS.INSIGHTS_READMISSION()
```
Then: Call GET_DRIVERS with LABEL='IS_RECENT' (last 3 months vs prior), METRIC='READMIT_30_FLAG' → save to `HOSPITAL360_ML.PREDICTIONS.PRED_READMISSION_DRIVERS`

**Model 4: INSIGHTS_LEAKAGE** — Top Insights for leakage drivers
```
CREATE SNOWFLAKE.ML.TOP_INSIGHTS HOSPITAL360_ML.MODELS.INSIGHTS_LEAKAGE()
```
Then: Call GET_DRIVERS with LABEL='IS_RECENT', METRIC='LEAKAGE_FLAG' → save to `HOSPITAL360_ML.PREDICTIONS.PRED_LEAKAGE_DRIVERS`

### File 3: `infrastructure/15_ml_predictions.sql` — Generate and persist predictions

Create prediction output tables in `HOSPITAL360_ML.PREDICTIONS`:

1. **PRED_ENCOUNTER_VOLUME** — 90-day forecast with columns: SERIES, TS, FORECAST, LOWER_BOUND, UPPER_BOUND
2. **PRED_DENIAL_ANOMALIES** — Anomaly flags on historical data: SERIES, TS, FORECAST, LOWER_BOUND, UPPER_BOUND, IS_ANOMALY, PERCENTILE, DENIAL_COUNT (actual)
3. **PRED_READMISSION_DRIVERS** — Top Insights output: CONTRIBUTOR, METRIC_CONTROL, METRIC_TEST, CONTRIBUTION, RELATIVE_CONTRIBUTION, GROWTH_RATE
4. **PRED_LEAKAGE_DRIVERS** — Same structure as readmission drivers
