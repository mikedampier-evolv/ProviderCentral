## Week 7: Cortex Agent — Agentic Hospital Intelligence

### Overview
Create a Cortex Agent object that wraps the Week 6 semantic view with agentic orchestration, enabling multi-step reasoning, tool selection, and auto-execution of SQL. The agent will be accessible via Snowsight's native agent UI AND via a new Streamlit page that calls the Agent REST API.

### Key Architectural Decision: Container Runtime
Cortex Agent APIs are **NOT supported** from SiS warehouse runtime. Two deliverables:
1. **Agent object** — standalone, accessible via Snowsight (zero friction)
2. **Streamlit agent page** — requires converting the app to **container runtime** using compute pool `SYSTEM_COMPUTE_POOL_CPU` (already ACTIVE)

### Deliverables

#### Step 1: `infrastructure/19_cortex_agent.sql` — Agent DDL
- `CREATE OR REPLACE AGENT HOSPITAL360_APP.CORTEX_ANALYST.HOSPITAL360_AGENT` with YAML spec:
  - **Model**: `auto` (auto-selects best available)
  - **Tools**: `cortex_analyst_text_to_sql` referencing the existing semantic view + `cortex_analyst_sql_exec` for auto-executing generated SQL
  - **Instructions**: Hospital-specific system prompt, orchestration guidance, response formatting, sample questions
  - **Budget**: 60 seconds, 16000 tokens
  - **Profile**: display_name, avatar color
- Grant `USAGE ON AGENT` to all 4 H360 roles
- Grant `CREATE AGENT` on schema to SYSADMIN

#### Step 2: `streamlit/pages/7_cortex_agent.py` — Agent Chat Page
- Conversational chat UI calling `POST /api/v2/databases/{db}/schemas/{schema}/agents/{name}/run` via `_snowflake.send_snow_api_request()`
- Thread management for multi-turn conversations
- Parse `system_execute_sql` response blocks (new format per Apr 13, 2026 change) — display SQL + results + charts
- Parse text blocks for agent reasoning
- Sidebar with sample questions + thread management

#### Step 3: Convert Streamlit to Container Runtime
- `CREATE OR REPLACE STREAMLIT` with `RUNTIME_NAME = 'SYSTEM$ST_CONTAINER_RUNTIME_PY3_11'` and `COMPUTE_POOL = SYSTEM_COMPUTE_POOL_CPU`
- Update `environment.yml` → `requirements.txt` (container runtime uses pip, not conda)
- Re-deploy all files to stage, add live version, re-grant USAGE

#### Step 4: Update `streamlit/streamlit_app.py`
- Add "Cortex Agent" card linking to the new agent page
- Brief description of agentic capabilities vs the simpler Analyst page

#### Step 5: Deploy & Verify
- Upload all files to stage
- Recreate Streamlit with container runtime
- Test agent creation, Snowsight access, and Streamlit agent page
