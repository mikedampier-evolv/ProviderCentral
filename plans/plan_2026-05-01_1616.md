## Convert Markdown Slide Deck to PowerPoint (.pptx)

### Context
- Source file: `slides/hospital360_demo_deck.md` (468 lines, 15 slides)
- `python-pptx` is not installed but can be added with `pip install python-pptx` (pulls only 2 small packages; `lxml`, `pillow`, `typing-extensions` already present)
- No pandoc, Marp, or LibreOffice available

### Approach
Write a Python script that uses `python-pptx` to programmatically generate a polished `.pptx` file. The script will:
- Parse each `---`-delimited slide from the markdown
- Apply a consistent Snowflake-branded color scheme (blue `#29B5E8` headers, dark backgrounds for title slides, white body slides)
- Map markdown content types to appropriate slide layouts:
  - `# Title` → Title slide layout (large centered text)
  - `## Subtitle` → Section header or subtitle text
  - Bullet lists → Text boxes with proper indentation for bold/nested items
  - Markdown tables → native PowerPoint table objects with styled headers
  - Code blocks → monospace text boxes with light gray background
  - Speaker notes / walkthrough steps → PowerPoint speaker notes pane
- Set standard widescreen 16:9 aspect ratio
- Add a small "Hospital 360 | Snowflake" footer on each slide

### Implementation Steps

1. **Install python-pptx**: `pip install python-pptx`
2. **Create generator script**: `slides/generate_pptx.py` — Python script that:
   - Reads `hospital360_demo_deck.md`
   - Splits on `---` into 15 slide blocks
   - Parses each block's markdown structure (headings, bullets, tables, code)
   - Generates a `.pptx` with styled slides
3. **Run the script** to produce `slides/hospital360_demo_deck.pptx`
4. **Verify** the output file exists and has 15 slides

### Critical Files
- `slides/hospital360_demo_deck.md` — Source content to convert
- `slides/generate_pptx.py` — New script to create (the generator)
- `slides/hospital360_demo_deck.pptx` — Output file
