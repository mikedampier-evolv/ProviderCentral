## Implementation Steps

### Step 1: Create `streamlit/chart_theme.py` — shared chart styling module

A single module all pages import that provides:
- **`H360_TEMPLATE`** — a custom Plotly template (registered via `pio.templates`) with:
  - Dark background (`#000000` plot bg, `#1A1A1A` paper bg)
  - White text, gridlines at 10% opacity
  - Consistent font (Inter/sans-serif)
  - Default color sequence (Snowflake blue `#29B5E8` primary, then a curated 8-color palette with good contrast on black)
  - Bar marker styling: rounded corners via `marker_line`, subtle gradient via `colorscale` defaults
  - Line styling: width=2.5, smooth curves
- **`apply_style(fig, height=350)`** — helper that applies the template + common layout overrides (margins, legend position, hover mode)
- **`COLORS`** — named color constants (primary, secondary, accent, danger, warning, success) for manual use
- **`bar_gradient(fig, color)`** — applies a vertical gradient effect on bar charts using `marker.color` with opacity-varied list
- **`glow_line(fig, trace_idx, color)`** — adds a "glow" effect behind a line trace using a wider, semi-transparent duplicate trace
