## Context

Snowflake's `CREATE ALERT` requires:
- A condition (SELECT that returns rows when the alert should fire)
- An action (typically `CALL SYSTEM$SEND_EMAIL(...)`)
- A schedule (CRON or interval)
- A warehouse to evaluate the condition

The existing email feature pattern in the chat uses: an icon button on assistant messages → inline form → calls a Flask endpoint → executes SQL via REST API. We'll follow the same pattern for alerts.

## Implementation Steps

### 1. Add `/api/alert` endpoint to Flask (`server/app.py`)

Accepts:
```json
{
  "name": "high_readmission_alert",
  "condition": "SELECT 1 FROM HOSPITAL360_CUR.ANALYTICS.MART_READMISSION_LOS WHERE READMISSION_RATE > 0.15 LIMIT 1",
  "action_email": "mike.dampier@slalom.com",
  "schedule": "60"  // minutes, or cron expression
}
```

Constructs and executes:
```sql
CREATE OR REPLACE ALERT HOSPITAL360_APP.ALERTS.<name>
  WAREHOUSE = H360_BI_WH
  SCHEDULE = '<schedule> MINUTE'
  IF (EXISTS (<condition>))
  THEN
    CALL SYSTEM$SEND_EMAIL('H360_EMAIL_INT', '<email>', 'Alert: <name>', 'Alert condition was met.');
```

Then executes `ALTER ALERT <name> RESUME` (alerts are suspended on creation).

### 2. Add `createAlert` function to `useChatAgent.ts`

New exported function that POSTs to `/api/alert`. Tracks status similar to `emailStatus` with a new `alertStatus` state.

### 3. Add alert button + form to `ChatWidget.tsx`

Next to the Email button on assistant messages, add a bell icon "Alert" button. Clicking it shows a small inline form:
- **Condition** (pre-filled from the agent's last SQL if available, or user types a metric condition like "readmission_rate > 0.15")
- **Email** (where to send the alert)
- **Frequency** (dropdown: every 1 hour, 6 hours, daily)

Submit creates the alert. Show a status toast like the email feature.

### 4. Create the ALERTS schema in Snowflake

One-time DDL: `CREATE SCHEMA IF NOT EXISTS HOSPITAL360_APP.ALERTS` to house the alert objects.

### 5. Grant privileges

`GRANT EXECUTE ALERT ON ACCOUNT TO ROLE SYSADMIN` and `GRANT USAGE ON SCHEMA HOSPITAL360_APP.ALERTS TO ROLE SYSADMIN`.

## Verification

- Click the alert bell icon on a chat response
- Fill in a condition (e.g., `SELECT 1 FROM HOSPITAL360_CUR.ANALYTICS.MART_READMISSION_LOS HAVING AVG(READMISSION_RATE) > 0.10`)
- Set email and frequency
- Confirm "Alert created" toast appears
- Run `SHOW ALERTS IN SCHEMA HOSPITAL360_APP.ALERTS` to verify the alert exists and is STARTED
